# TreeSitter 2.0.1

A big upgrade. Highlights:

- **~370 languages**, via `tree_sitter_language_pack`
- **No more manual compilation.** Language parsers are prebuilt and downloaded/cached automatically the first time you use a language
- **Language injections**: nested languages (JS/CSS in HTML, code in fenced Markdown blocks, etc.) are now parsed and fully navigable; selection, symbols, and node inspection all understand injected trees, not just the outer buffer's syntax
- Goto/select symbol now indexes injected code too, can be called with a flag to only look for symbols in your selection, and falls back to the community "tags" query for any languages that don't ship a bundled symbols query
- Runs on Sublime Text's Python 3.14 plugin host

See the [README](https://github.com/sublime-treesitter/TreeSitter) for details.

Thanks for using TreeSitter!
